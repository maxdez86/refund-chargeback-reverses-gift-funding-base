Purpose

Use this folder as the variant base

Duplicate apps/web/public/v1 to create v2, v3, or other temporary versions without touching the main React app.

Files

Keep each version self-contained

  • index.html for structure
  • styles.css for version-specific styling
  • Add script.js only if a variant needs JavaScript
  • Add version-local assets inside /v1/assets if needed

Notes

Temporary by design

This variant is published as plain static files alongside the main site. There is no shared component system, no alternate app entrypoint, and no permanent abstraction.
